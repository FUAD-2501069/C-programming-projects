C Programming Projects

A collection of C programs written while studying Computer Programming (CSE) as part of my EEE coursework at RUET. This repository is organized by topic, with each folder containing programs related to a specific concept.

📂 Repository Structure
C-programming-projects/
├── Array-1D/
│   └── One-dimensional array problems (largest/smallest element, search, etc.)
├── Array-2D/
│   └── Two-dimensional array / matrix problems
├── For-loop/
│   └── Programs based on for-loop logic (patterns, series, primes, etc.)
├── Bubble-sort/
│   └── Sorting algorithm implementations
└── Basic-programs/
    └── Fundamental C programs (area, fibonacci, etc.)
🧠 Topics Covered
Loops and control flow (for, while, nested loops)
Arrays (1D and 2D)
Sorting algorithms
Number theory programs (prime, Armstrong, perfect numbers, etc.)
Pattern printing
Basic math and geometry programs
🛠️ Tools Used
Language: C
Compiler: GCC / Code::Blocks
👤 About
I'm a first-year EEE student at RUET (Rajshahi University of Engineering & Technology), Bangladesh. This repository documents my journey of learning C programming through hands-on practice and problem-solving.
